# IntroCard Website

Static website for IntroCard (introcard.pro), ready for GitHub Pages.

## Deploy

1. Upload all files and folders to the `introcard` GitHub repository.
2. Go to Settings > Pages.
3. Select `Deploy from a branch`, branch `main`, folder `/root`.
4. Set custom domain to `introcard.pro`.
5. Configure DNS with your domain registrar.
6. Enable Enforce HTTPS after DNS has propagated.

## Images

`/images` contains the App Store marketing screenshots (`appstore_01` … `appstore_10`)
used on the landing page, plus `AppIcon.png` used as favicon and nav logo.
Keep the same filenames or update the HTML references.

## Remaining placeholder

- Replace the "App Store coming soon" button link in `index.html` once the app is approved.
